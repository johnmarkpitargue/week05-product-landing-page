🚀 Week 5 – Client-Server Technologies

This week, I designed and developed a Responsive Product Landing Page for **Belen's Special Palabok**, a real home-based Filipino food business, using **Laravel, Tailwind CSS, and Blade Components**.

I focused on:
🧩 Building 7 reusable Blade Components (navbar, hero, feature cards, pricing cards, testimonials, buttons, footer)
📱 Applying mobile-first responsive design with Flexbox and CSS Grid
🎨 Designing a warm, food-forward color palette and consistent typography system

Comparing my initial wireframe with the final version really showed me how much thoughtful UI decisions — spacing, hierarchy, hover states — improve both usability and how "real" a small business can look online.
